# Changelog

## v1.1.0

- All translations now live in one place (`js_variables`) with a shared `translate()` partial. Idea by [elchininet](https://github.com/elchininet).
- Any language listed in the file is picked up automatically. Missing languages fall back to English.
- "Marketplace" is now translatable like the other items.
- README: new "Add your language" section.

## v1.0.0

- First release: Developer Tools, Devices & Services, Automations & Scenes, Apps and Marketplace shortcuts.
- Shortcuts are visible to administrators only.
- Names follow the user's profile language (Greek or English).
- "Apps" and "Marketplace" hide themselves where they don't exist.
